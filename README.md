# International-Student-Admissions-Analytics

## Project Overview
This project analyzes international student admissions data to provide
visibility into recruitment performance, application trends, geographic
demand, program demand, and admissions pipeline efficiency.

An interactive dashboard was developed in Google Looker Studio to help
support data-driven admissions and recruitment decisions.

## Technologies Used
- Google Looker Studio
- Data Analytics
- Data Visualization
- Dashboard Development
- KPI Analysis

## Key Metrics
- Total Applications: 5,000
- Total Admitted: 3,256
- Pending Applications: 1,744
- Conversion Rate: 65.1%
- Pending Rate: 34.9%

## Analysis
The project analyzes:
- Applications by country
- Program demand
- Applications by college
- Monthly admission trends
- Admission conversion rates
- Pending application pipeline
- Geographic recruitment patterns

## Dashboard Features
- KPI scorecards
- Geographic application map
- Top 10 program analysis
- College-level application analysis
- Monthly admission trend
- Application source filters
- Admission year filters

## Key Insights
- International applications show significant geographic concentration.
- STEM and technology-focused programs account for substantial applicant demand.
- Application volume varies significantly across colleges.
- Monthly admissions trends help identify periods of higher processing activity.
- Pipeline metrics help identify pending workload and admissions efficiency.
